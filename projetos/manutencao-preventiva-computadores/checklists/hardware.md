# Checklist de hardware

## Identificação

- [ ] Nome ou identificação do equipamento
- [ ] Fabricante e modelo
- [ ] Número de patrimônio, quando aplicável
- [ ] Usuário responsável
- [ ] Data da verificação

## Verificação física

- [ ] Equipamento liga normalmente
- [ ] Fonte e cabo de energia em boas condições
- [ ] Cabo de vídeo conectado
- [ ] Teclado funcionando
- [ ] Mouse funcionando
- [ ] Monitor funcionando
- [ ] Portas USB testadas
- [ ] Sinais de aquecimento excessivo
- [ ] Ruídos incomuns
- [ ] Ventilação desobstruída
- [ ] Limpeza externa necessária
