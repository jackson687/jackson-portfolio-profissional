# Checklist de segurança básica

- [ ] Usuário não compartilhou a senha
- [ ] Nenhuma senha foi registrada
- [ ] Bloqueio de tela configurado
- [ ] Atualizações do Windows verificadas
- [ ] Proteção contra ameaças verificada
- [ ] Aplicativos desconhecidos identificados
- [ ] Arquivos importantes possuem backup
- [ ] Permissões não foram alteradas sem autorização
- [ ] Dispositivos USB desconhecidos não foram conectados
- [ ] Dados sensíveis não foram enviados para serviços externos

## Observação

Este checklist não substitui uma auditoria de segurança ou as políticas oficiais da organização.
