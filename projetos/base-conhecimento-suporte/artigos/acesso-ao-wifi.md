# Procedimento: acesso ao Wi-Fi

## Objetivo

Investigar problemas de conexão Wi-Fi em um computador Windows.

## Perguntas iniciais

- A rede aparece na lista?
- Outros dispositivos conseguem conectar?
- A senha foi alterada recentemente?
- O problema acontece em outros locais?
- Existe alguma mensagem de erro?

## Procedimento

1. Confirmar se o Wi-Fi está ativado.
2. Verificar se o modo avião está desligado.
3. Confirmar o nome da rede correta.
4. Reconectar usando a senha informada pelo usuário, sem registrá-la.
5. Verificar se o computador recebeu um endereço IP.
6. Testar o gateway e a resolução de nomes.
7. Validar o acesso a um site autorizado.

## Quando encaminhar

Encaminhar quando vários dispositivos estiverem sem conexão, houver falha no roteador, problema de cobertura ou necessidade de alteração na infraestrutura.
