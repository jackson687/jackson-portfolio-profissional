# Checklist de atendimento

## Identificação

- [ ] Nome do usuário
- [ ] Equipamento utilizado
- [ ] Sistema operacional
- [ ] Data e horário
- [ ] Descrição do problema
- [ ] Mensagem de erro, quando houver
- [ ] O problema começou quando?
- [ ] O problema afeta apenas este usuário ou outras pessoas?

## Diagnóstico

- [ ] O problema foi reproduzido?
- [ ] Houve alguma alteração recente?
- [ ] Foi testada outra conta?
- [ ] Foi testado outro cabo, porta ou equipamento?
- [ ] Foram verificadas atualizações pendentes?
- [ ] Foram registrados os testes realizados?

## Encerramento

- [ ] A solução foi aplicada?
- [ ] O usuário confirmou que voltou a funcionar?
- [ ] O procedimento foi registrado?
- [ ] Existe alguma recomendação preventiva?
- [ ] É necessário encaminhar o chamado?

## Cuidados

- Não apagar arquivos sem confirmação.
- Não solicitar senhas do usuário.
- Não executar comandos desconhecidos.
- Fazer backup antes de alterações de risco.
- Registrar alterações realizadas.
