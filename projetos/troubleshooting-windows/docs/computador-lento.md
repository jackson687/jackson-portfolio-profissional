# Diagnóstico: computador lento

## Sintomas comuns

- Aplicativos demoram para abrir.
- Sistema apresenta travamentos.
- Inicialização muito demorada.
- Ventoinha funcionando continuamente.
- Pouco espaço disponível.

## Perguntas ao usuário

- A lentidão começou quando?
- O problema ocorre em todos os programas?
- Houve instalação recente?
- O computador apresenta mensagens de erro?
- O problema acontece logo após iniciar o Windows?
- Há arquivos importantes sem backup?

## Procedimento

1. Confirmar o sintoma com o usuário.
2. Verificar o uso de CPU, memória e disco no Gerenciador de Tarefas.
3. Conferir o espaço livre no disco.
4. Identificar aplicativos iniciando automaticamente.
5. Verificar atualizações pendentes.
6. Conferir se há sinais de superaquecimento.
7. Reiniciar o computador e validar o comportamento.

## Possíveis soluções

- Fechar processos que não são necessários.
- Liberar espaço com segurança.
- Desativar programas de inicialização desnecessários.
- Atualizar o Windows e os drivers aprovados.
- Orientar backup e avaliação de upgrade quando o hardware for insuficiente.

## Quando encaminhar

Encaminhar quando houver suspeita de falha física, superaquecimento persistente, perda de dados ou necessidade de alteração de hardware.
