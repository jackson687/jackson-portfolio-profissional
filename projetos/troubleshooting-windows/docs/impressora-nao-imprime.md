# Diagnóstico: impressora não imprime

## Sintomas comuns

- Documento fica preso na fila.
- Impressora aparece offline.
- Impressão sai com erro.
- Usuário não encontra a impressora.

## Perguntas ao usuário

- A impressora está ligada?
- Há papel e tinta ou toner?
- Outros usuários conseguem imprimir?
- O problema ocorre em todos os programas?
- A impressora é USB ou de rede?
- Houve troca recente de senha ou rede?

## Procedimento

1. Verificar energia, papel e mensagens no equipamento.
2. Confirmar se a impressora correta está selecionada.
3. Conferir o status online ou offline.
4. Limpar documentos presos na fila.
5. Testar uma página de teste.
6. Confirmar conexão USB ou endereço de rede.
7. Verificar o driver aprovado pela empresa.
8. Validar uma nova impressão.

## Quando encaminhar

Encaminhar quando houver falha física, necessidade de troca de suprimento, problema de rede compartilhada ou permissão de instalação de driver.
